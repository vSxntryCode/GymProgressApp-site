Privacy Policy

How the current version of GymProgressApp handles information.

Last updated: 24 September 2026

Summary

GymProgressApp is currently designed as a local-first app. The developer does not currently operate an account system, cloud-sync service, analytics service, advertising system or tracking system for the app.

The app does not intentionally transmit the workout, nutrition, bodyweight, recovery, profile or enhanced-tracking records you enter to a developer-operated server.

Information stored on your device

Depending on which features you use, the app can store information such as:

  • profile display name and local onboarding state;
  • workout templates, workout history, exercises, sets, loads, repetitions, RIR, progression, XP, Rank and achievements;
  • saved foods, meals, nutrition targets and food-diary entries;
  • bodyweight records;
  • self-reported recovery information;
  • enhanced-tracking records such as phases, administrations, symptoms, health markers and bloodwork entries; and
  • local database diagnostics and backup/restore state needed to operate those features.

These records are stored in the app's local SQLite database unless you deliberately export a backup.

Manual backup and restore

GymProgressApp lets you create a SQLite backup and present it to the iOS share sheet. You choose where that file goes. If you save or send it through Files, iCloud Drive or another provider, that provider's privacy practices apply to the copy you choose to place there.

Backup files can contain the same private information that is stored in the app, including health- or enhanced-related records. Treat exported backup files as sensitive.

Restore reads a file you select, validates it locally, creates a pre-restore rollback backup, and replaces the local database only after explicit confirmation.

Public release website hosting

When this privacy/support website is published through GitHub Pages, GitHub hosts the website infrastructure. GitHub states that a visitor's IP address is logged and stored for security purposes when a GitHub Pages site is visited. This website-hosting activity is separate from the GymProgressApp mobile app's local product database.

GitHub's own privacy terms apply to its hosting and security processing.

Data collection, analytics, ads and tracking

The current application source does not configure developer-operated analytics, advertising, behavioral tracking, cloud accounts or cloud synchronization.

This statement does not mean that your operating system, App Store, device backup settings, network provider, file-storage provider, or other services you independently choose cannot process technical or account information under their own terms.

Permissions

The current app does not configure product features that request camera, microphone, contacts, precise location, Photos, HealthKit or notification access. Development builds may use local-network discovery to connect to the development server; that is not a product feature.

Data control

Because the current product stores its records locally, access to and removal of app data are primarily controlled through the app and the device. Manual backup export gives you a copy that you can keep independently.

Deleting the app may remove data that exists only inside the app sandbox. Keep a current external backup before uninstalling if the records matter to you.

Changes to this policy

This policy must be updated if the product adds features such as accounts, developer-operated cloud sync, analytics, advertising, tracking or other material data handling changes.

Contact
