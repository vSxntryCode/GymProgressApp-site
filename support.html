GymProgressApp Support

Help with local data, backups, restores and general app issues.

Current contact channel

Pre-release support contact: GitHub @vSxntryCode.

A dedicated public support contact must be confirmed before App Store submission. Avoid posting private app records or database backup files in a public support message.

Before requesting help

  • Open Profile → Your Data and run Data Health.
  • If the app still opens, create a fresh manual backup before troubleshooting destructive data issues.
  • Record the app version, iOS version and exact error text.
  • Describe what you expected and what happened instead without including private records.

Backup and restore support

Backups are SQLite files and can contain private app records. Keep them private.

Restore accepts only a compatible backup that passes schema, SQLite integrity, foreign-key and expected-table checks. A pre-restore rollback backup is created before live data is replaced.

What the app does not currently provide

The current release architecture does not include a developer-operated user account, cloud sync, remote data recovery or a server-side copy of your local app database.
